# FrameIsle experimental FFmpeg LGPL source materials

This directory contains only third-party source archives, their notices, and
build recipes. It does not contain FrameIsle application source, user media,
credentials, certificates or application binaries.

The archive includes FFmpeg 7.1.5, dav1d, libass, FreeType (FTL), HarfBuzz,
FriBidi and source-built host tools, with exact upstream archive hashes.
No third-party source patches are applied. Framework install-name and packaging
changes are documented in the included builder.

This source publication supports development verification. It is not an app
release, an assertion of patent clearance, or confirmation that physical-device
replacement/signing and all distribution obligations have been satisfied.
